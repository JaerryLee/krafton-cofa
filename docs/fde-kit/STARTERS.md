# 오픈소스 후보와 선택 기준

아래 후보는 시험 전에 구조와 시작 명령을 익혀두는 용도입니다. 준비 키트의 Python 서버는 추가 설치 없이 로컬에서 확인할 수 있습니다. 외부 코드 사용이 허용된 상황에서는 제공된 저장소와 런타임을 확인하고 필요한 부분만 도입하세요.

| 과제 조건 | 먼저 검토할 시작점 | 확인할 내용 |
| --- | --- | --- |
| 로컬 샘플 기반 의사결정 도구 | 이 키트의 `server.py`와 `dashboard.html` | 한 번의 실행으로 샘플이 보이는가. 판정 로직을 순수 함수로 뽑아 테스트할 수 있는가. |
| 데이터 탐색과 필터가 중심인 과제 | [Streamlit 공식 앱 튜토리얼](https://docs.streamlit.io/get-started/tutorials/create-an-app) | 설치와 실행이 가능한가. 사용자가 필요한 핵심 표와 선택 입력을 빠르게 만들 수 있는가. |
| 기존 JS UI의 확장 또는 새 화면 | [Vite 공식 시작 가이드](https://vite.dev/guide/) | 제공된 Node 버전과 빌드·배포 환경이 맞는가. 현재 프레임워크를 유지할 수 있는가. |
| API, DB, 인증이 실제 요구이며 컨테이너 사용이 가능한 과제 | [Full Stack FastAPI Template 공식 저장소](https://github.com/fastapi/full-stack-fastapi-template) | 환경 준비 시간과 유지 부담을 감당할 수 있는가. 권한과 데이터 저장이 검증 대상인가. |

가장 먼저 제공된 프로젝트를 실행해 보세요. 새 스택 도입은 첫 사용자 경로를 늦추는지, 허용되는 의존성인지, 재현할 시간이 있는지 검토한 후 결정하세요. 참고 코드를 가져올 때는 라이선스와 출처 표시 조건도 확인하세요.
