# 공개 자료와 연습 방식

- Luka의 FDE 코파톤 참가 후기는 실무자 역할과의 인터뷰, 약 225분 빌드, 제출 후 짧은 확인 질문을 겪은 한 참가자의 기록입니다. 작성자가 아쉬워한 점을 두 도메인 리허설, 바로 실행되는 키트, 사전 탐색한 참고 저장소, 새 세션 인수인계로 바꿨습니다. 모의시험의 질문과 시나리오는 연습용으로 새로 만들었습니다. [크래프톤 FDE 코파톤 후기](https://brunch.co.kr/@luma/5)
- 공식 코파톤 페이지는 실무 환경을 닮은 과제와 AI 협업에 초점을 둡니다. Cofa Probe 공식 소개는 산출물과 대화·검증 기록, 사후 설명을 함께 살피는 흐름을 설명합니다. 연습에서는 결과를 재실행할 명령과 판단 근거를 남기도록 했습니다. [공식 코파톤](https://cofathon.getcofa.com/) · [Cofa Probe](https://www.getcofa.com/ko/probe)
- HackerRank의 프로젝트형 AI 지원 평가는 환경 설정에 따라 AI가 할 수 있는 범위를 다르게 둘 수 있습니다. 리허설 시작 단계에 허용된 도구, 실행 환경, 외부 자료 범위 확인을 넣었습니다. [HackerRank AI-Assisted Tests](https://support.hackerrank.com/articles/1152916770-ai-assisted-tests)
- Anthropic의 장시간 에이전트 실험은 진행 기록을 읽고 작동 상태를 다시 검증하는 방식이 세션 사이의 맥락을 이어주는 사례를 제시합니다. 키트에는 새 세션이 입구 명령부터 재실행하는 인수인계 양식을 넣었습니다. [Anthropic의 에이전트 하네스 실험](https://www.anthropic.com/research/effective-harnesses-for-long-running-agents)
- OpenAI FDE의 현장 사례는 고객 워크플로 이해와 실제 관찰 가능한 성공 지표를 활용합니다. 모의 인터뷰에서 최근 실패, 책임자, 기준값과 성공 측정을 확인하도록 구성했습니다. [OpenAI의 FDE 현장 사례](https://openai.com/index/forward-deployed-engineering-means/)

응시자의 실제 과제·배점·제출 시간은 시험 안내를 기준으로 확인하세요.
