# FDE 로컬 연습 작업 지침

- 작업 시작 시 과제의 브리프, 실무자와 합의한 조건, 이전 세션의 인수인계를 읽는다. 사용자가 준 최신 요구가 우선이다.
- 수정 전에 대상 파일, 변경할 동작, 검증할 입력과 기대값을 짧게 정리한다. 샘플과 기존 실행 진입점은 과제에서 변경이 요구되는 범위만 수정한다.
- 규칙에 따른 계산과 상태 판정은 직접 검사할 수 있는 코드로 둔다. 인터뷰 내용이 모호하거나 충돌하면 후보 해석과 사용자 영향, 확인할 질문을 제시한다.
- 한 번에 사용자 경로 하나를 끝까지 연결한다. 실패를 고칠 때는 재현 입력과 기대값을 고정한 뒤 같은 명령으로 다시 실행한다.
- 설치된 도구로 시작한다. 새 의존성은 과제 환경에서 사용할 수 있고 얻는 이점이 분명할 때 도입한다.
- 가상 데이터로 실행한다. 출력에는 실행 명령, 실제 결과, 실행하지 못한 검사, 남은 위험을 각각 기록한다.
- 세션을 넘길 때 WORKSHEET.md의 인수인계 양식을 사용한다. 다음 사람이 찾아갈 코드 위치와 첫 명령을 남긴다.
